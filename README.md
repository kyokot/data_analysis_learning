# 統計みちしるべ

統計検定4級・3級を独学でめざす人のための、**非公式**の学習ナビです。

無料で読める良い教材は、すでにたくさんあります。足りないのは「どの順に・どこを読み・本当に分かったか・いつ受験してよいか」を決めてくれる案内役です。このサイトは次のことだけをします。

- 公式の出題範囲に沿って、学ぶ内容を小さな単元に分け、**今日の一歩を1つだけ**示す
- 各単元で**無料の外部教材を1本**選び、読みどころを添えてリンクする（本文の転載はしない）
- 読んだかどうかではなく、**確認テストに合格したか**で先へ進む。翌日以降の定着チェックに通って初めて「定着」とする
- 間違えた問題を1日後・3日後・7日後に出し直す。計算問題は**数値を変えた類題**で出し直し、答えの暗記を防ぐ
- 定着した単元も、14日後・30日後・60日後に「おさらい」として出す
- 練習では出さない**模試専用の問題**で、30問・60分の模試を行う
- ホーム画面に追加でき、一度開けば電波がなくても学習できる（PWA）

企画の検討内容は [docs/PLAN.md](docs/PLAN.md)、MVP の次の改善施策は [docs/ROADMAP.md](docs/ROADMAP.md) にあります。

> 「統計検定」は一般財団法人統計質保証推進協会の登録商標です。このサイトは同協会とは関係がありません。
> 問題と要点はオリジナルで、AIを使って作成しています（検証の状況は `content/verification.json`）。専門家の監修は受けていません。

## 動かす

Node.js 22 以上が必要です。

```bash
npm install
npm run dev        # 開発サーバー
npm run build      # dist/ に静的サイトを出力
npm run preview    # ビルド結果を確認
```

サーバーもアカウントも不要な静的サイトです。進み具合は利用者のブラウザ（localStorage）にだけ保存されます。

### 確認用のコマンド

```bash
npm run check             # 型検査 + コンテンツ検証 + テスト
npm run validate:content  # content/ の検証（数式・図表・問題構成・模試の配分）
npm test                  # 学習エンジンと、実際の教材を使った結合テスト
npm run check:links       # 外部教材リンクの生存確認（ステータスとページタイトル）
```

### 公開する（GitHub Pages）

1. リポジトリの Settings → Pages → Source を「GitHub Actions」にする
2. Actions の「GitHub Pages に公開」を手動で実行する
   （`.github/workflows/deploy.yml` の `push` のコメントを外すと、main への反映のたびに自動公開されます）

`base: './'` でビルドしているので、サブパスに置いても動きます。

## 構成

```
content/                 教材データ（ここを差し替えれば別の試験にも使える）
  curriculum.json        ステージ・単元・前提関係・模試の配分
  units/<単元id>.json    単元ごとの要点カードと問題
  resources.json         外部教材の提供元とリンク（単元への対応・役割・読みどころ）
  exam-guide.json        試験の形式・公式リンク（確認日つき）
  AUTHORING.md           要点と問題の執筆規約
src/
  content/               型・スキーマ・検証・簡易マークアップ
  engine/                学習の決まり（React にも保存先にも依存しない純粋関数）
    select.ts            出題の選び方（確認テスト・定着チェック・復習・模試）
    progress.ts          解答の記録、習得の判定、模試の採点
    planner.ts           今日の一歩、ペース、受験の目安
  generators/            類題ジェネレーター（units/<単元id>.ts に計算問題の作り方を書く）
  store/                 localStorage への保存、バックアップ
  ui/ pages/             画面
scripts/                 コンテンツ検証・解き直し検証・リンク確認
tests/                   エンジンのテスト、教材との結合テスト
```

## 学習の決まり

| 項目 | 決まり |
|---|---|
| 確認テスト | 5問中4問以上で合格（未出題の問題を優先して出す） |
| 定着チェック | 合格の翌日以降に別の3問。2問以上で定着、届かなければ学習中に戻す |
| 復習 | 間違えた問題を1日後・3日後・7日後に出し直す（類題があれば数値違いで）。1回12問まで |
| おさらい | 定着した単元を14日後・30日後・60日後に2問ずつ。間違えたら14日に戻す |
| 模試 | 模試専用の問題から30問・60分。結果に「初見だった問題」の正答率を表示 |
| 受験の目安 | 全単元に合格・定着し、模試と公式問題集で8割 |

定数は `src/engine/model.ts` の `RULES` にあります。

## 教材を直す・増やす

1. `content/AUTHORING.md` を読む（定義の統一・問題数・図表の書き方）
2. `content/units/<単元id>.json` を編集する
3. `npm run validate:content -- --unit <単元id>` でエラーが無いことを確認する
4. 書いた本人とは別の人（または別のAI）が、正答を見ずに解き直す

   ```bash
   npx tsx scripts/blind.ts export <単元id>             # 正答と解説を除いた問題を出力
   npx tsx scripts/blind.ts check <単元id> answers.json  # 解答 {"問題id": 添字} を正答と突き合わせ
   ```

外部教材のリンクは `content/resources.json` で管理します。`checkedOn` はリンク確認（存在とタイトル）が通った日、`verifiedOn` は人が本文を読んで確かめた日です。画面には、どこまで確認できているかをそのまま表示します。

### 類題ジェネレーターを足す

計算で答えが決まる技能は、数値を変えた類題を何問でも作れます。`src/generators/units/<単元id>.ts` に `generators` を書くと自動で登録されます（書き方は `src/generators/units/central.ts` が見本）。

- 正答はコードで計算し、誤答は「典型的な取り違え」を同じデータに当てはめて計算する（`kit.ts` の `choicesFrom`）
- `replaces` に、同じ計算を問う固定の問題（practice）の id を書くと、その問題を間違えたときの出し直しで類題が出る
- `npx vitest run tests/generators.test.ts` で、全ジェネレーターを300の種で検査する（形・重複・数式・偏り）
- `GEN_SAMPLE=<単元id> npx vitest run tests/gen-sample.test.ts` で見本を表示して、目で確かめる

### 別の資格に使う

学習エンジンは試験に依存しません。`content/` 以下（カリキュラム・単元・教材リンク・受験ガイド）を差し替え、`src/config.ts` の名称を変えれば、別の試験の学習ナビになります。

## 既知の限界

- 問題は全364問について、作成時のプログラムによる再計算と、正答を隠した別のAIによる解き直し（不一致0件）を行っています（`content/verification.json`）。ただし作成も検証も同じ系統のAIなので、共通の思い込みは見逃しうるうえ、専門家の監修は受けていません。
- 外部教材の URL は、CI のリンク確認で**ページの存在とタイトルの一致**まで確かめています（`checkedOn`）。ただし**リンク先の本文を読んでの内容確認はできていません**。公開前に主教材だけでも目で確かめ、確認できたら `verifiedOn` を入れることをおすすめします。CI（`.github/workflows/links.yml`）が週1回、リンクの生存とページタイトルを確認します。
- 模試の難しさは本試験に合わせて較正していません。最終確認には公式問題集を使ってください。
- 進み具合は端末のブラウザにしか保存されません（資料室 → 設定とバックアップ で書き出せます）。
