# 企画書: 統計みちしるべ（仮称）

独学で資格試験の合格まで案内する学習ナビ。最初の対象は統計検定4級・3級。
2026-11-26 時点の検討内容と、MVP で採った判断・捨てた判断の記録です。

## 1. 解く問題

無料の良い教材はすでに十分にある（依頼者の調査で約60サイト）。それでも独学者が合格まで届かないのは、教材が足りないからではなく、次の4つを**自分で判断している**からだと考えた。

1. **次に何をやるか**を毎回自分で決めている（教材の海で迷い、得意な所ばかり解く）
2. **読んだ＝分かった**と思い込む（確かめる関門がない）
3. **間違えても戻る場所が分からない**（×と正解だけでは、何を取り違えたかが分からない）
4. **いつ受験してよいか**判断できない（見たことのある問題の正答率を実力と誤認する）

したがって作るべきものは教材ではなく、**順序・関門・診断・受験判定**の4つ。解説そのものは外部の無料教材に任せ、当サイトは「案内役」と「試験官」に徹する。

## 2. 検討の進め方

- 立場の異なる3つの企画案（学習科学／初学者の体験／懐疑的なPM）を互いに見せずに作り、別に、たたき台の案を批判だけする査読を1本走らせた。
- 公式の出題範囲と試験形式、競合サイトの現状を調査した（この環境からは対象サイトを直接取得できず、検索結果の要約に基づく。§7 参照）。

### 3案がそろって主張したこと（＝採用）

| 論点 | 採った判断 |
|---|---|
| 主役 | 地図やリンク集ではなく「**今日の一歩**」を1つだけ出す。優先順位は固定（復習 → 学習中の単元 → 次の単元 → 模試） |
| 外部教材 | 1単元につき**主教材1本**＋「合わなかったら」の補助。必ず「読みどころ」を添える。本文の転載・埋め込みはしない |
| 進む条件 | 「読んだ」チェックでは進まない。**確認テストに合格**したときだけ進む |
| 習得の定義 | 1回の正解を信用しない。確認テスト（5問中4問）に合格 →**翌日以降に別の3問**（定着チェック）→ 通って初めて「定着」。落ちたら学習中に戻す |
| 誤答 | 全選択肢に「どう取り違えるとこの答えになるか」を書く。選んだ誤答の説明を最初に見せる |
| 模試 | **模試専用の問題を取り置く**（確認テスト・復習には出さない）。結果には「初見だった問題の数と正答率」を必ず出す |
| 表示の正直さ | 「合格圏」「合格保証」は言わない。「この模試での正答率」と書く。非公式・AI作成・専門家の監修なしを明記する |

### 査読（批判役）の指摘で変えたこと

| 指摘 | 対応 |
|---|---|
| 5問中4問の1回判定はノイズが大きく、受け直すと暗記テストになる | 二段判定（当日＋別日・別問題）にした。受け直しは未出題の問題を優先。「わからない」ボタンで当て推量を減らす |
| 4級のゴールが曖昧。数学の復習を冒頭に置くと統計に入る前に脱落する | コースを「4級コース → 4級模試 → 3級の差分コース → 3級模試」に組み直した。数学は学習ルートから外し、**必要な単元の直前に補習として案内**する |
| 全問を間隔反復に入れると復習が溢れて新しい単元に進めなくなる | 復習に回すのは**間違えた問題だけ**（1日後・3日後・7日後）。1回12問を上限にして残りは持ち越す |
| リンクが「貼ってあるだけ」で、実在と内容が未検証 | CIで全リンクの存在とページタイトルの一致を確認した（以後も週1回）。リンク切れに備えて「サイト内を検索」を全リンクに付けた。本文を読んでの内容確認は未実施（§7） |
| 4級の範囲に移動平均・分布の形・パレート図などが入っている | 公式範囲表（検索結果ベース）と突き合わせ、4級の単元の到達目標を修正した |
| 前提グラフのUI、開始時の実力診断、60サイトの一覧は不要 | 画面は一本道の「ルート」にした。実力診断は作らず、**知っている単元は確認テストに合格すれば飛ばせる**形で兼ねた。教材一覧は単元で実際に使うサイトだけに絞った |

### 意見が割れて、今回は見送ったこと

- **数値を入れ替える問題ジェネレーター**（正答をコードで計算し、類題を無限に出す）: 3案とも推したが、MVPでは固定の問題＋独立した解き直し検証にとどめた。次の最有力候補。
- **誤答タグの集計**（「平均と中央値の混同」などの誤解の種類ごとに弱点を出す）: 選択肢ごとの説明までは入れた。分類体系と集計は次の段階。
- **外部の非公式問題サイトへの誘導**: 査読は「品質を保証できないので切る」。依頼者の調査では重要視されているため、単元の流れには入れず、資料室に「追加の演習（内容は未確認）」として置いた。

## 3. 競合との違い

調査した範囲（統計ロードマップ、青の統計学、Transparently、ケンテイラボ、statistical.jp など）では、次の空白があった。

- 自前の教材に閉じており、**他サイトの無料教材を単元別に横断して案内する中立のナビ**がない
- 単元ごとの習熟判定で「進む／戻る」を決める仕組み、日を空けた再確認がない（復習は誤答の再出題まで。有料のものもある）
- **4級から3級までを一本道**でつなぎ、数学の学び直しまで戻れるものが少ない

逆に、教科書的な解説・用語集・可視化ツールは既存サイトで足りているので作らない。

## 4. MVP の範囲

**入れたもの**

- 学習ルート: 公式範囲表に対応づけた28単元（4級10・3級18）＋数学の補習3単元。前提関係つき
- 単元ページ: ゴール → 先に見ておく問い → 主教材リンク（読みどころつき）→ 要点カード → 確認テスト
- 確認テスト・定着チェック・間違えた問題の復習（1/3/7日）・補強ドリル
- 模試（30問・60分・見直しの印・問題一覧・自動採点・分野別結果・全問解説）。4級と3級
- 今日の一歩（次にやることを1つ）、ペースの見通し、受験の目安（4条件）、外部模試・公式問題集の自己採点の記録
- 資料室: 教材一覧、受験ガイド（公式リンク・確認日つき）、設定、バックアップ（書き出し・復元）
- オリジナルの要点と問題。図表（表・棒・帯・円・折れ線・ヒストグラム・箱ひげ図・散布図・ドットプロット・幹葉図・正規分布）はデータから描画
- 登録なし・サーバーなし・解析タグなし。進み具合は端末のブラウザにのみ保存

**入れなかったもの（理由）**

- アカウントと端末間の同期（サーバーが要る。バックアップ文字列で代替）
- 連続日数・バッジなどの仕掛け（合格に寄与しない。指標は「合格した単元」と「初見の模試の正答率」だけ）
- 自前の長文解説・動画（既存の無料教材で足りる。作るのは3分で見返せる要点まで）
- 実行時のAI生成問題・AIチャット（正答を検証できない問題は出さない）

## 5. 学習の決まり（エンジンの仕様）

| 項目 | 決まり |
|---|---|
| 確認テスト | 練習用8問から5問（未出題を優先、基礎1問＋標準以上2問を必ず含む）。4問以上で合格 |
| 定着チェック | 合格の翌日以降、確認テストに出なかった3問。2問以上で定着。届かなければ学習中に戻す |
| 復習 | 間違えた問題・「わからない」を1日後に出し直し、正解するたびに3日後・7日後。7日後も正解で卒業。1回12問まで |
| 模試 | 分野別の配分どおりに、模試専用の未出題問題 → 模試専用の既出問題 → 練習用の順で組む。3級は各分野の3分の2以上を3級の単元から |
| 受験の目安 | ①全単元に合格 ②全単元が定着 ③模試で80%以上 ④公式問題集など初見の問題で80%以上（推奨） |

配分（分野ごとの出題数）は当サイトが決めた目安で、公式の配点ではない。

## 6. コンテンツの作り方と検証

- 仕様は `content/AUTHORING.md`（定義の統一: 分散は n で割る、四分位数は高校数学Iの方式、など）。
- 機械検証（`npm run validate:content`）: スキーマ、数式の構文、図表の数値の整合、問題数と難易度の配分、正答位置の偏り、模試の配分を満たせるか。
- 内容の検証: 作成時の数値の再計算（全単元で実施）と、正答を隠した別担当による解き直し（`scripts/blind.ts`）。不一致の問題は直すか捨てる。解き直しを終えた単元は `content/verification.json` に記録し、サイトの「このサイトについて」に件数を表示する。
- 結果（2026-11-26〜27）: 全31単元・364問を解き直し、正答キーとの不一致は0件。あいまいさの指摘があった問題のうち5問は、言い回しや注記を直した。
- それでも作成と検証は同じ系統のAIで、共通の思い込みは見逃しうる。**専門家の監修は受けていない**。各問題に「誤りを報告」の導線を置き、サイト内で明記している。

## 7. 既知の限界とリスク

| リスク | 現状と対策 |
|---|---|
| 問題・要点の誤り | AI作成。再計算と解き直し（全問・不一致0件）はしたが、同じ系統のAIによる検証なので誤りは残りうる。報告導線、公式テキストを基準にする旨を明記。統計の専門家・合格者によるレビューが次の課題 |
| リンク先の本文は未確認 | 作成環境から対象サイトを取得できなかったため、候補は検索結果から集めた。その後 CI のリンク確認で、全リンクの存在とページタイトルの一致を確認した（切れていた3件は削除）。本文を読んでの照合は未了で、画面にもその旨を表示している。公開前に人の目で主教材だけでも開いて確認するのが望ましい |
| リンクの方針 | 各サイトの方針を公開前に確認する（統計局は出典明示でリンク自由。統計WEBはサイトポリシーに記載あり）。転載・埋め込み・ロゴの使用はしない |
| 模試の難しさ | 本試験に合わせた較正はしていない。CBTの過去問題は非公開で照合できない。最終確認は公式問題集で行うよう案内 |
| 進み具合の消失 | ブラウザのデータ消去で失われる。バックアップの書き出し・復元と、定期的な声かけで補う |
| 商標 | 「統計検定」は登録商標。サイト名には含めず、全ページに非公式である旨を表示 |
| 試験情報の変更 | 受験料・合格基準などは変わりうる。受験ガイドに確認日を表示し、公式ページへ案内 |

## 8. 次の一手（優先順）

1. 主教材リンクを人の目で確認し、`verifiedOn` を入れる。単元ごとの「読む見出し・飛ばす箇所・定義の違い」を具体化する
2. 計算問題のジェネレーター（数値替えの類題、正答はコードで算出）
3. 誤答の種類ごとの弱点集計と、それに応じた出題
4. 統計の専門家・合格者による問題のレビュー
5. PWA 化（オフライン・ホーム画面追加）
6. ほかの資格への展開: エンジンは試験に依存しない。`content/` の差し替えで別の試験に対応できる
