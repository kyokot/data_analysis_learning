### 1. 外部教材の本文照合

- 環境のネットワーク設定に教材サイト16ホストを追加し、全リンクの本文を取得して照合する。
- 各リンクで、単元の到達目標を本当に教えているかを確かめ、読みどころを「実際の見出し名」で書き直す。
- 当サイトの定義（n で割る分散、高校数学Iの四分位数）と違う教材には注記を付ける。範囲外（2級以上）の内容は「どこから先は読まなくてよいか」を書く。
- 照合できたリンクには `verifiedOn` を入れ、画面の「内容は未確認」の表示を外す。
- 数学の補習3単元は、トップページではなく個別の授業・記事ページにリンクする。

### 2. 類題ジェネレーター

- 計算で答えが決まる技能（割合、代表値、四分位数、分散、標準化、相関、回帰、確率、二項分布、正規分布、信頼区間、検定 など）ごとに、数値をランダムに作って問題・図・選択肢・解説を組み立てる関数を書く。
- **正答はコードで計算**し、誤答は「典型的な取り違え」を同じデータに当てはめて計算する（例: 中央値を並べ替えずに求める、n−1 で割る、行比率と列比率を取り違える）。
- 種（seed）から決定的に作るので、問題番号（`gen:<技能>~<seed>`）だけで同じ問題を再現できる。
- テストで、各ジェネレーターを数百の種で動かし、正答が1つだけ・選択肢が重ならない・数式が表示できる・同じ種で同じ問題になる、を確かめる。
- 使い道:
  - 間違えた問題の出し直しで、同じ技能の**別の数値の類題**を出す（答えの暗記を防ぐ）
  - 単元ページの「類題ドリル」（何回でも新しい問題）
- 模試には使わない（模試は検証済みの固定問題で、難しさをそろえる）。

### 3. 定着後の間隔復習

- 定着チェックに通った単元を、14日後・30日後・60日後に「おさらい」として復習に混ぜる（1単元2問、類題があれば類題）。
- 2問とも正解なら次の間隔へ、間違えたら14日に戻し、間違えた問題は通常の出し直しにも入れる。
- 1回の復習の上限（12問）の中で、おさらいは4問までにする。

### 4. PWA

- ホーム画面に追加でき、一度開いた後は電波がなくても学習できる。
- 進み具合はこれまでどおり端末内にだけ保存する。

## 実施結果（2026-11-27）

| 施策 | 結果 |
|---|---|
| 1. 本文照合 | 全112リンクの本文を取得して照合（`verifiedOn` を記録）。読みどころを実際の見出し名で書き直し、当サイトと定義が違う箇所・範囲外の箇所を注記。単元を教えていない・トップページだけのリンク7件を削除し、数学の補習に個別の授業・記事ページを追加。主教材は各単元ちょうど1本 |
| 2. 類題ジェネレーター | 54種類（計算を扱う22単元。考え方を問う9単元は対象外）。固定の練習問題49問に「間違えたら類題で出し直す」対応を付けた。性質テスト（各300の種）と、別担当による見本の解き直し（計約2,000問）で確認し、見つかった不具合・不自然な表現を修正 |
| 3. おさらい | 定着した単元を14日→30日→60日後に2問ずつ。類題がある単元は類題で出す。既存の保存データにも予定を付ける |
| 4. PWA | マニフェスト・アイコン・ビルド時に作るサービスワーカー。初回表示の後は通信を切っても単元ページと数式が表示されることを確認 |

類題の作成は、同じ系統のAIが書き・確かめたもので、専門家の監修は受けていない。

## 次回以降の進め方

- 5（誤解タグ）は、全問の選択肢にタグを付ける作業が中心。タグの体系（20種類程度）を先に決め、単元ごとに付けて、進み具合のページに「よくやる取り違え」を出す。
- 6（本試験形式）は、公式問題集で形式・難しさの比率を確かめるところから始める。問題文の転載はしない。
- 9（他の資格）は、`content/` の構造が試験に依存しないことを確かめる意味でも、2級の数単元で試作するのがよい。
